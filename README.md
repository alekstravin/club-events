# Клуб ИИИИ — публичное зеркало

Портал: https://alekstravin.github.io/club-events/

Серверное зеркало и админка: https://club-iiii-events-gateway.expertlime1.chatgpt.site/

GitHub Pages показывает опубликованные заседания и актуальные свободные места.
Форма отправляет заявку в существующую базу портала через HTTPS-шлюз.
Подтверждение, персональный отказ и закрытая админка открываются на шлюзе.
Новые события появляются автоматически: обновлять GitHub при создании события не требуется.

В репозитории только публичный интерфейс и QR каналов. Персональные данные,
таблицы участников, пароли и ключи доступа здесь не хранятся.
